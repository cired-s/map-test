度量衡器地圖程式

重要提示

請先將地圖所需的 JSON 資料備妥（如轉換後的檔案），再執行地圖程式。

地圖程式需選擇所需JSON 資料、縣市、度量衡器、檢定結果，執行統計篩選，才會顯示圖標。

JSON 檔案清單與說明

說明： 以下為各度量衡器excle資料檔轉換後的 JSON 檔清單，另請注意各度量衡器excle資料欄位正確性。

  • scale-data.json: 非自動衡器 (市場磅秤)
  • weighbridge-data.json: 固定地秤
  • tank-data.json: 非連續累計自動衡器 (槽秤)
  • loading-scale-data.json: 重力式自動裝料衡器(裝料秤)
  • dispenser-data.json: 油量計 (加油機)
  • gas-machine-data.json: 液化石油氣流量計 (加氣機)
  • charger-data.json: 電動車輛供電設備 (充電樁)
  • intervalspeed-data.json: 區間平均速率裝置
  • ex-management-scale-data.json: 優良衡器計量管理市場
  • ex-management-dispenser-data.json: 優良油量計計量管理加油站
